SHIVA EVENT - SUPABASE STORAGE

Bucket used by the project:
shiva-event-images

The admin service form now uploads selected image files to Supabase Storage.
Only the resulting public image URLs are stored in the services table.

Supabase dashboard setup already required:
- Bucket: shiva-event-images
- Bucket visibility: Public
- Storage policies: public SELECT + authenticated admin INSERT/UPDATE/DELETE

Admin upload flow:
Admin Panel -> Add/Edit Service -> Select image(s) -> Save Service
-> Supabase Storage -> public URL -> services table -> customer website

Do not put a Supabase secret/service_role key in the frontend.
Only the publishable/anon public key belongs in supabase-config.js.
